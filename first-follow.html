Section 4

FIRST & FOLLOW Sets

The two sets every predictive parser is built on — computed with a full iteration trace, then used to test whether the grammar is LL(1).

4.1

Definitions and rules

FIRST set definition

FIRST(α) is the set of terminals that can appear as the first symbol of some string derived from α. If α can derive the empty string, ε is also in FIRST(α).

Rules:

  1. If X is a terminal, FIRST(X) = { X }.
  2. If X → ε is a production, add ε to FIRST(X).
  3. If X → Y1Y2…Yk: add FIRST(Y1) − {ε} to FIRST(X). If Y1 can derive ε, also add FIRST(Y2) − {ε}, and so on. If every Y can derive ε, add ε to FIRST(X).

FOLLOW set definition

FOLLOW(A) is the set of terminals that can appear immediately to the right of A in some sentential form derived from the start symbol.

Rules:

  1. Put $ in FOLLOW(S) for the start symbol S.
  2. For a production A → αBβ: add FIRST(β) − {ε} to FOLLOW(B).
  3. For A → αB, or A → αBβ where β can derive ε: add everything in FOLLOW(A) to FOLLOW(B).
💡
ε is never a member of a FOLLOW set. FOLLOW answers "what real token can come next", and the end marker $ covers "nothing comes next". Keep applying the rules until no set changes — this is a fixed-point computation.

The LL(1) test rule

Build the predictive table: for each production A → α,

  • for every terminal a in FIRST(α), put A → α in M[A, a];
  • if ε is in FIRST(α), put A → α in M[A, b] for every b in FOLLOW(A) (including $ if present).

The grammar is LL(1) if and only if no cell ends up with two or more productions.
